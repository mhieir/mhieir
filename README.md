## Research

**Proof checking — EPFL, DEDIS Laboratory**  
During my research internship with Prof. Bryan Ford, I implemented and tested inference rules in Standard ML and developed a code-extractable proof checker for Reflective Grounded Arithmetic in Isabelle/HOL. The implementation is maintained in a private research repository.

**[Geometric Freeze-Tag Problem](https://github.com/mhieir/Geometric-Freeze-Tag-Problem)**  
Collaborative research on geometric robot-activation problems. The repository contains makespan calculations and 3D visualizations. Related work appeared at AAMAS 2025 and in [Autonomous Agents and Multi-Agent Systems](https://doi.org/10.1007/s10458-026-09738-8).

**[Control-Flow Integrity](https://github.com/mhieir/CFI)**  
C implementation of FIND_DICON for discovering divergence–convergence blocks in control-flow graphs. Related paper accepted at DFTS 2026.

**[SAYAC Compiler](https://github.com/mhieir/SAYAC_Compiler)**  
Contributions to the Mini-C backend for the SAYAC embedded processor: register and memory management, control flow, and function calls.
